## 1. V2 SQLite（.eprj2）

### 1.1 元数据表【实测列名】

- projects(18列): name="New Project_日期" 默认名无意义
- schematics(12列): uuid/name/display_name/sheet_count/sort
- documents(16列): uuid/display_title/docType/dataStr/schematic_uuid/
  sort_ticket…；docType: 1=页 3=PCB；display_title 会同名，取页一律 uuid
- components(21列): SYMBOL 库（Symbol uuid 空间）
- devices(22列): Device 空间（description 列=型号真源）
- attributes(key/value/device_uuid,4706行): 桥接 key='Symbol'
- 空壳表 boards/coppers/texts/backups 等（0行）：新版才写
- 加密相关：project_structures/history_data/project_history_<branch>

### 1.2 dataStr【官方+实测】

"base64" 前缀+base64(gzip(NDJSON)) 或明文 NDJSON。

### 1.3 原理图页记录（docType=1）【官方§2/§3+实测】

- DOCTYPE [,"SCH","1.1"]；HEAD [{ORIGIN_X/Y,…}] 原点可选
- COMPONENT [id,partId(2),x(3),y(4),rot(5),mirror(6),{attrs}(7),locked(8)]
  变换序=旋转→镜像→平移【§3.3.2】
- ATTR [id,parent(2),key(3),value(4),showKey(5),showValue(6),X(7),Y(8),
  rot(9),styleId(10),locked(11)]；X/Y null=从未显示；挂 WIRE 的
  key=NET/"Global Net Name" 即网络名【§2.4】
- WIRE [id,[段…],styleId,locked]，段=[x1,y1,x2,y2,…] 连续折线；
  导线必须带 NET 属性
- TEXT [id,x,y,rot,text,fontStyleId,locked]
- BUS 同 WIRE；BUSENTRY [id,busId(2),order(3),endX,endY,rot]
- RECT [id,x1,y1,x2,y2,圆角X(6),圆角Y(7),rot绕点1(8),styleId,locked]
- POLY [id,[xy…](2),闭合(3),styleId,locked]
- CIRCLE [id,cx,cy,r,styleId,locked]
- ARC [id,起X,起Y,参考X,参考Y,终X,终Y,styleId,locked] 三点均在圆上

样式表（文件级）：FONTSTYLE [id,颜色,背景色,字体名,大小,斜体,加粗,
下划线,删除线,垂直对齐,水平对齐]，除 id 外均可 null=默认；
LINESTYLE [id,颜色,线型,填充色,宽度]。
Symbol 类型【§3.3.1】：2=Part 17=Block(CBB) 18=NetFlag 19=NetPort
20=Sheet 21=NoneElec 22=Short。
模板覆盖【§3.3/§4】：COMPONENT 内 ATTR 覆盖模板同名属性；标题栏即此机制
——模板符号存键+显示位置，实例只存值(X/Y=null)。PIN 覆盖 parent=
实例cid+PIN编号拼接（NO_CONNECT 同理）。

### 1.4 符号文档（components.dataStr, DOCTYPE=SYMBOL）

同 §1.3 图元 + PART 分节 [,"子库",{BBOX:[xmin,y1,xmax,y2]}]【§5】。
HEAD.originX/Y 需先减【实测 .epro esym 有、SQLite 多为 0】。

### 1.5 PCB 文档（docType=3）【官方PCB规范+实测】

- COMPONENT [id,分组(2),层(3),X(4),Y(5),rot(6),{attrs}(7),locked(8)]
  attrs 内联含 Unique ID(ggeN)=SCH↔PCB 映射键
- ATTR [id,分组(2),parent(3),层(4),X(5),Y(6),key(7),value(8),showKey(9),
  showValue(10),字体名(11),字号(12),粗细(13),加粗(14),斜体(15),对齐(16),
  rot(17),反相(18),反相尺寸(19),镜像(20),锁定(21)] —— 与 SCH 布局完全不同
- PAD_NET [id,器件实例cid(1),焊盘号(2),网络名(3),封装内padId(4,可选)]
- NET [id,名称(1),类型(2),特殊色(3),隐藏飞线(4),差分名(5),差分正(6),等长组(7)]
- LAYER [id,编号(1),类型(2),别名(3),状态(4)=1用/2显/4锁可加,
  激活色,激活透明度,非激活色,非激活透明度]；SIGNAL/PLANE/SUBSTRATE
  出现顺序=物理叠层顺序
- VIA [id,分组,NET,层规则名,X,Y,孔径,盘径,类型(0普/1缝合),…]
- PAD [id,分组,NET,层(顶/底/多),盘号,X,Y,旋转,孔ref,默认盘ref,
  特殊盘组,孔偏移X,Y,孔旋,plated,功能(0普/1测点/2标识),…]
- LINE [id,分组,NET,层,X1,Y1,X2,Y2,线宽,locked]；ARC/CARC 角度逆时针正
- STRING [id,分组,层,X,Y,内容,字体名,字号,粗细,加粗,斜体,对齐(0左顶…
  8右底),rot,反相,反相尺寸,镜像,locked]
- 多边形体系 L/ARC/CARC/C 贝塞尔/R 矩形/CIRCLE 模式；POLY/FILL/REGION/
  POUR/POURED/TEARDROP/CONNECT(一对多)/PROP/ITEM_ORDER/RULE 系列
- CANVAS [原点X,原点Y,单位mm,格X,格Y,…] 单位不影响数据单位

## 2. .epro（V2 ZIP）【实测】

zip 组：SYMBOL/*.esym、FOOTPRINT/*.efoo、INSTANCE/*.eins、PCB/*.epcb、
SHEET/*.esch(+空扩展名占位)、POUR/PANEL/BLOB/FONT 单例目录。
project.json 键：config/boards/devices/symbols/footprints/schematics/
pcbs/panels。boards[name]={schematic,pcb}；pcbs={uuid:"文件名.brd"}。
*.epcb 与 SQLite docType=3 记录布局完全一致（COMPONENT/ATTR/PAD_NET 同），
但开头 DOCTYPE 可能标 "FOOTPRINT"（导出器怪癖，按内容解析勿信 DOCTYPE）。
esym 有 HEAD.originX/originY 需先减。
**时间/编辑人元数据：不存在**（2026-08-24 全键扫描实证）——
project.json 仅 devices.version=器件库版本号（非编辑时间）；
.esch/.esym HEAD 仅 version 计数器；.efoo/.epcb HEAD.editorVersion=
编辑器软件版本；唯一时间=ZIP 条目导出时刻（全文件同一瞬间）。
对比：.epro2 导出保留了 DOCHEAD.updateTime/user——两代导出格式差异。

## 3. .epro2 / 新版加密 .eprj2（V3）【实测】

epru 行 = head||body|；DOCHEAD 开文档（uuid+docType 字符串：
BOARD/SCH/SCH_PAGE/SYMBOL/DEVICE/FOOTPRINT/**PCB**/INSTANCE/CONFIG）；
META 存 title/board/zIndex/attributes；同 uuid 多段按 (段序,ticket)
双键合并。涡流 epro2 分布：FOOTPRINT82/SYMBOL162/DEVICE163/BOARD3/SCH6/
SCH_PAGE17/PCB3。
V3 PCB body keys：COMPONENT{partitionId,groupId,layerId,x,y,angle,
attrs{Unique ID…}}；ATTR{parentId,key,value,keyVisible,valueVisible,
fontSize,angle,…}；PAD_NET head.id=["PAD_NET",cid,pin,padId]+body.padNet；
NET 名在 head.id JSON 数组。工具 sheet_records(doc_type=3) 统一转
V2 布局（见 lceda_reader.py Epro2DB）。
跨格式 UID 稳定：epro2 备份 PCB2 与 SQLite PCB2 同 125 元件全匹配。
