# 器件与板子

> 版本说明：基于 EasyEDA Pro V3 格式规范 §10-11

## 器件库 (Component Library)

### 器件定义

| 字段 | 类型 | 说明 |
|------|------|------|
| `uuid` | String | 器件 UUID |
| `name` | String | 器件名称 |
| `prefix` | String | 前缀 (如 R, C, U) |
| `description` | String | 描述 |
| `symbolUuid` | String | 原理图符号 UUID |
| `footprintUuid` | String | PCB 封装 UUID |
| `attributes` | Object | 属性字典 |

### 器件属性

| 字段 | 类型 | 说明 |
|------|------|------|
| `Manufacturer` | String | 制造商 |
| `MPN` | String | 制造商料号 |
| `Supplier` | String | 供应商 |
| `SPN` | String | 供应商料号 |
| `Datasheet` | String | 数据手册 URL |
| `Value` | String | 器件值 |
| `Tolerance` | String | 容差 |
| `Power` | String | 功率 |
| `Voltage` | String | 电压 |


## 原理图符号 (Symbol)

### 符号结构

| 字段 | 类型 | 说明 |
|------|------|------|
| `uuid` | String | 符号 UUID |
| `name` | String | 符号名称 |
| `prefix` | String | 前缀 |
| `units` | Array | 单元数组 |
| `pins` | Array | 引脚数组 |

### 引脚定义 (PIN)

| 字段 | 类型 | 说明 |
|------|------|------|
| `gId` | String | 图形 ID |
| `x` | Number | X 坐标 (mm) |
| `y` | Number | Y 坐标 (mm) |
| `number` | String | 引脚编号 |
| `name` | String | 引脚名称 |
| `length` | Number | 引脚长度 (mm) |
| `rotation` | Number | 旋转角度 (度) |
| `pinType` | String | 引脚类型 |
| `showNumber` | Boolean | 显示编号 |
| `showName` | Boolean | 显示名称 |

### pinType 类型

| 值 | 说明 |
|---|------|-----------|
| `unspecified` | 未指定 |
| `input` | 输入 |
| `output` | 输出 |
| `bidirectional` | 双向 |
| `power_in` | 电源输入 |
| `power_out` | 电源输出 |
| `passive` | 被动 |
| `open_collector` | 开集 |
| `open_emitter` | 开射 |

## 多单元器件

### 单元定义

| 字段 | 类型 | 说明 |
|------|------|------|
| `unitId` | String | 单元 ID |
| `name` | String | 单元名称 |
| `pins` | Array | 该单元的引脚 |

### 门交换与引脚交换

| 字段 | 类型 | 说明 |
|------|------|------|
| `unitSwap` | Boolean | 允许门交换 |
| `pinSwap` | Array | 可交换引脚组 |

pinSwap 格式：`[["1", "2"], ["3", "4"]]` 表示引脚 1-2 可交换，3-4 可交换。


## 板子定义 (Board)

### 板框 (BOARD_OUTLINE)

| 字段 | 类型 | 说明 |
|------|------|------|
| `gId` | String | 图形 ID |
| `layerid` | String | 层 ID (BoardOutline) |
| `pointArr` | Array | 顶点数组 |
| `locked` | Boolean | 是否锁定 |

### 板子属性

| 字段 | 类型 | 说明 |
|------|------|------|
| `thickness` | Number | 板厚 (mm) |
| `layers` | Number | 层数 |
| `material` | String | 材料 (如 FR-4) |
| `copperThickness` | Number | 铜厚 (μm) |
| `surfaceFinish` | String | 表面处理 |
| `color` | String | 阻焊颜色 |

### surfaceFinish 类型

| 值 | 说明 |
|---|------|
| `HASL` | 有铅喷锡 |
| `HASL_LEAD_FREE` | 无铅喷锡 |
| `ENIG` | 化金 |
| `OSP` | 有机保焊膜 |
| `IMMERSION_SILVER` | 沉银 |
| `IMMERSION_TIN` | 沉锡 |

## 安装孔 (MOUNTING_HOLE)

| 字段 | 类型 | 说明 |
|------|------|------|
| `gId` | String | 图形 ID |
| `x` | Number | X 坐标 (mm) |
| `y` | Number | Y 坐标 (mm) |
| `diameter` | Number | 孔径 (mm) |
| `plated` | Boolean | 是否镀铜 |


## 示例：器件定义

```json
{
  "uuid": "comp_res_0805",
  "name": "RES_0805",
  "prefix": "R",
  "description": "0805 Resistor",
  "symbolUuid": "sym_resistor",
  "footprintUuid": "fp_0805",
  "attributes": {
    "Manufacturer": "Yageo",
    "MPN": "RC0805FR-07*",
    "Tolerance": "1%",
    "Power": "0.125W"
  }
}
```

## 示例：引脚定义

```json
{
  "gId": "pin_001",
  "x": 0,
  "y": 0,
  "number": "1",
  "name": "VCC",
  "length": 2.54,
  "rotation": 0,
  "pinType": "power_in",
  "showNumber": true,
  "showName": true
}
```

```json
{

  "layers": 4,
  "material": "FR-4",
  "copperThickness": 35,
  "surfaceFinish": "ENIG",
  "color": "Green"

```
