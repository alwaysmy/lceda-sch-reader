# 通用文件头格式

通用文件头用于标识文档类型和版本信息，便于前向兼容。

## 格式

```json
["DOCTYPE", "SCH", "1.0"]
```

## 字段说明

1. `DOCTYPE`：文档类型标识。
2. 文档类型：可选值包括 `SCH`、`SYMBOL`、`INSTANCE`、`PCB`、`FOOTPRINT`、`PANEL` 等。
3. 文档格式版本号：每次发布设计格式变动的版本前都要调整版本号。

文件格式带上版本号后，可以通过版本号做前向兼容，不需要每个图元都做前向兼容。例如将：

```json
["ARC", "e5", 340, 210, ...]
```

调整成：

```json
["ARC", "e5", [340, 210], ...]
```

只需要调整版本号即可，不需要在格式上预留以前的位置。

## HEAD 头信息

```json
["HEAD", {"editorVersion": "4.7.8", "importFlag": 0}]
```

1. `HEAD`：文档头标识。
2. 内部参数 Key-Value：为编辑器附加信息，用于数据分析等功能，可选。
