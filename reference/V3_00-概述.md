# 概述

> 基于官方格式说明文档（版本 2025102101）。

## 1. 文档约定

- 所具有范围特性的图元，以及文件本身，都称作**块级图元**
- 工程的所有数据在一个文件里，首行必须是文档头（DOCHEAD 块级图元），用于分块
- 以行为单位，每一行都是由两个合法的 JSON 对象拼接而成
- JSON 对象的键名采用**驼峰命名**（camelCase）
- 所有图元都要带上文件内的**唯一编号**
- 旋转角度以**逆时针方向为正**，统一使用角度制
- 若无特殊说明，所有坐标、长度、大小统一使用 **0.01 inch** 为单位
- 所有颜色都使用 `#RRGGBB` 的方式表达，`""` 表示无颜色（完全透明）
- 所有样式内容（除了样式标识和编号）都可以置 `null` 表示采用默认样式
- 所有使用"是否XXXX"描述的属性，都使用布尔类型表示
- 几乎所有图元都带有**锁定**参数，锁定后：不能拖拽、不能删除、不能通过鼠标键盘调整大小或形状

## 2. 行数据

整个数据可当做一个大字符串，根据分隔符 `\n` 分割为一行一行数据，按行按顺序逐行解析。

每一行的数据，根据分隔符 `||` 可将一行数据分割成内外两层 JSON 对象数据：

```
外层数据 || 内层数据
```

### 2.1 外层数据

外层数据的类型定义是统一的，每一行数据的外层结构都一样：

| 键名 | 值类型 | 必需 | 描述 |
|------|--------|------|------|
| type | string | 是 | 类型名：用于识别该行属于哪种图元 |
| id | string | 是 | 唯一编号：文档内唯一，相同 id 表示同一数据 |
| ticket | number | 是 | 逻辑时钟：相同 id 的两条数据，保留 ticket 值大的一条 |

id 唯一编号的三种形式：
- **随机编号**：绝大部分图元 id 是 16 位随机字符编码
- **类型名**：有一些 id 值就是其数据类型名，与 type 字段一致
- **JSON 数组字符串**：有一些特殊图元，其 id 是类型名和其他字符组成的数组

### 示例

```json
{"type":"ATTR","id":"68ea867bde655fd2","ticket":2}||{"key":"Value","value":"100nF"}
```

### 2.2 内层数据

也是 JSON 对象，但每一种图元都对应一个内层数据类型，具体看各图元的类型定义。

## 3. 文档块

有一行特殊的数据，其外层数据的类型名为 `DOCHEAD`，称其为**文档头**，是一个块级图元，用于区分文档块。

文档数据的第一行必须是文档头，逐行解析时，当遇到文档头时，表示接下来的数据都属于该文档，直到遇到下一个文档头。

```
第一行 文档头
第二行 数据        ← 属于第一个文档块
第三行 数据        ← 属于第一个文档块
第四行 文档头
第五行 数据        ← 属于第二个文档块
第六行 数据        ← 属于第二个文档块
```

### 3.1 文档头 (DOCHEAD)

外层数据的类型名为 `DOCHEAD`，其内层数据：

| 键名 | 值类型 | 必需 | 描述 |
|------|--------|------|------|
| docType | EHeaderType | 是 | 文档类型：固定枚举值 |
| uuid | string | 是 | 文档编号：工程内唯一 |
| client | string | 是 | 终端标识：表示不同的用户 |
| updateTime | number | 是 | 更新时间：保存数据时的时间 |
| version | string | 是 | 版本：一般与更新时间保持一致 |

外层数据：文档头不记录唯一编号，不参与一致性数据比较，逻辑时钟仅递增当前工程最大逻辑时钟。

### 示例

```json
{"type":"DOCHEAD","ticket":1}||{"docType":"SCH_PAGE","client":"8e13a9703e0ad2c4","uuid":"2e14f5d942c47f54","updateTime":1760597173242,"version":"1760597173242"}
```

### EHeaderType 完整枚举表

| 值 | 文档类型 |
|----|----------|
| CONFIG | 工程配置 |
| BOARD | 板子 |
| SCH | 原理图 |
| SCH_PAGE | 原理图页 |
| PCB | PCB 页 |
| PANEL | 面板 |
| SYMBOL | 符号 |
| FOOTPRINT | 封装 |
| DEVICE | 器件 |
| BLOB | 二进制数据（图片） |
| INSTANCE | 实例属性 |
| PANEL_LIB | 面板库 |
| FONT | 字体 |
| VARIANT | 变体 |
| COMPONENT_GROUP | 元件分组 |
| COMPONENT_GROUP_DATA | 元件分组属性 |
| SIMULATION | 仿真页 |
