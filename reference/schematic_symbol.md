# SYMBOL 符号类型文档

## 文件头

```json
["DOCTYPE", "SYMBOL", "1.0"]
["HEAD", {"symbolType": 2}]
```

## HEAD 字段说明

1. `HEAD`：文档头标识。
2. 内部参数 Key-Value：
   - `symbolType`：为 Symbol 类型，给其它工具用于识别符号类型。XTools 核心逻辑不应关注这个属性。
   - 其它为编辑器附加信息，用于数据分析等功能，可选。

## PART 子库

`PART` 是一个块级元素。要求无任何图元在 `PART` 范围外。如果是单 Part 器件也必须有一个 `PART`，子库编号留空 `""`。

### 格式

```json
["PART", "1", {"BBOX": [-10, -20, 10, 20]}]
```

### 字段说明

1. `PART`：子库图元标识。
2. 子库编号。
3. 内部参数 Key-Value：
   - `BBOX`：为能刚好框住 PART 下所有图元的矩形包围盒任意对角的两个点。XTools 核心逻辑不应关注这个属性。
   - 其它为编辑器附加信息，用于数据分析等功能，可选。
