# 辅助文档类型

> 版本说明：基于 EasyEDA Pro V3 格式规范 §12-17

## BOM (Bill of Materials)

### BOM 文件结构

| 字段 | 类型 | 说明 |
|------|------|------|
| `head` | Object | 文件头信息 |
| `items` | Array | 物料清单项 |
| `settings` | Object | BOM 设置 |

### BOM 项定义

| 字段 | 类型 | 说明 |
|------|------|------|
| `designator` | String | 元件标识 (如 R1, R2) |
| `footprint` | String | 封装名称 |
| `quantity` | Number | 数量 |
| `manufacturer` | String | 制造商 |
| `mpn` | String | 制造商料号 |
| `supplier` | String | 供应商 |
| `spn` | String | 供应商料号 |
| `description` | String | 描述 |

### BOM 设置

| 字段 | 类型 | 说明 |
|------|------|------|
| `groupBy` | String | 分组方式 (value/mpn) |
| `sortBy` | String | 排序方式 |
| `columns` | Array | 显示列 |


## Pick and Place

### 坐标文件格式

| 字段 | 说明 |
|------|------|
| `Designator` | 元件标识 |
| `Mid X` | X 坐标 (mm) |
| `Mid Y` | Y 坐标 (mm) |
| `Layer` | 层 (Top/Bottom) |
| `Rotation` | 旋转角度 (度) |

### 文件格式

通常为 CSV 格式：

```csv
Designator,Mid X,Mid Y,Layer,Rotation
R1,10.5,20.3,Top,0
C1,15.2,25.8,Top,90
```

## 网表 (Netlist)

### 网表格式

EasyEDA Pro 支持多种网表格式：

| 格式 | 扩展名 | 说明 |
|------|--------|------|
| 标准格式 | `.net` | 通用网表格式 |
| Altium | `.NET` | Altium 格式 |
| PADS | `.asc` | PADS 格式 |
| Protel | `.net` | Protel 格式 |

### 网表结构

| 字段 | 类型 | 说明 |
|------|------|------|
| `components` | Array | 元件列表 |
| `nets` | Array | 网络列表 |

### 元件定义

| 字段 | 类型 | 说明 |
|------|------|------|
| `ref` | String | 元件标识 |
| `value` | String | 元件值 |
| `footprint` | String | 封装 |
| `pins` | Array | 引脚列表 |

### 网络定义

| 字段 | 类型 | 说明 |
|------|------|------|
| `name` | String | 网络名称 |
| `nodes` | Array | 节点列表 |

节点格式：`["R1-1", "C1-2"]` 表示 R1 的引脚 1 和 C1 的引脚 2。

## 3D 模型

### 支持格式

| 格式 | 扩展名 | 说明 |
|------|--------|------|
| STEP | `.step`, `.stp` | 标准 CAD 格式 |
| VRML | `.wrl` | 虚拟现实格式 |
| OBJ | `.obj` | 通用 3D 格式 |
| STL | `.stl` | 3D 打印格式 |

### 模型定义

| 字段 | 类型 | 说明 |
|------|------|------|
| `uuid` | String | 模型 UUID |
| `name` | String | 模型名称 |
| `path` | String | 文件路径 |
| `format` | String | 文件格式 |


## 设计规则检查 (DRC)

### DRC 报告结构

| 字段 | 类型 | 说明 |
|------|------|------|
| `errors` | Array | 错误列表 |
| `warnings` | Array | 警告列表 |
| `timestamp` | String | 检查时间 |

### 错误定义

| 字段 | 类型 | 说明 |
|------|------|------|
| `type` | String | 错误类型 |
| `severity` | String | 严重程度 |
| `message` | String | 错误信息 |
| `location` | Object | 位置信息 |

### 错误类型

| 类型 | 说明 |
|------|------|
| `clearance` | 间隙违规 |
| `track_width` | 走线宽度违规 |
| `via_size` | 过孔尺寸违规 |
| `hole_clearance` | 孔间隙违规 |
| `copper_edge` | 铜皮到边缘违规 |
| `silk_overlap` | 丝印重叠 |
| `unconnected` | 未连接 |

## 示例：BOM 项

```json
{
  "designator": "R1,R2,R3",
  "footprint": "RES_0805",
  "quantity": 3,
  "manufacturer": "Yageo",
  "mpn": "RC0805FR-0710KL",
  "description": "10K 1% 0805 Resistor"
}
```

## 示例：网络定义

```json
{
  "name": "VCC",
  "nodes": [
    "U1-1",
    "R1-1",
    "C1-1"
  ]
}
```

## 示例：DRC 错误

```json
{
  "type": "clearance",
  "severity": "error",
  "message": "Clearance violation between track and pad",
  "location": {
    "x": 25.4,
    "y": 50.8,
    "layer": "TopLayer"
  }
}
```
