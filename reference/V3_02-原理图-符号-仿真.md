# 原理图-符号-仿真

> 基于官方格式说明文档（版本 2025102101）。

原理图页（SCH_PAGE）、符号（SYMBOL）和仿真页（SIMULATION）的图元属性目前是共用的，只有个别地方有差异。

## META（基本信息）

不同的文档类型对应的基本信息不一样，其外层数据类型名都为 `META`。

### 原理图页

| 键名 | 值类型 | 必需 | 描述 |
|------|--------|------|------|
| title | string | 是 | 文档名称 |
| source | string | 是 | 来源的 uuid（工程库独有） |
| zIndex | number | 是 | 排序大小 |
| schematic | string | 是 | 所属原理图 |

### 符号

| 键名 | 值类型 | 必需 | 描述 |
|------|--------|------|------|
| title | string | 是 | 名称 |
| description | string | 是 | 库描述 |
| tags | string[] | 是 | 自定义分类 |
| source | string | 是 | 来源的 uuid（工程库独有） |
| docType | number | 是 | 库类型 |


### 仿真

| 键名 | 值类型 | 必需 | 描述 |
|------|--------|------|------|
| title | string | 是 | 文档名称 |
| source | string | 是 | 来源的 uuid（工程库独有） |
| zIndex | number | 是 | 排序大小 |
| docType | number | 是 | 文档类型 |

## CANVAS（画布配置）

画布附加信息，目前仅记录了原点位置。

| 键名 | 值类型 | 必需 | 描述 |
|------|--------|------|------|
| originX | number | 是 | 画布原点 X 坐标 |
| originY | number | 是 | 画布原点 Y 坐标 |

### 示例

```json
{"type":"CANVAS","id":"CANVAS","ticket":1}||{"originX":0,"originY":0}
```

## 基础图元格式

### PART（部件）

只有符号页才有，如果是单 Part 符号也必须有一个 PART。符号页的所有图元带上对应的部件编号，表示归属于该部件。

| 键名 | 值类型 | 必需 | 描述 |
|------|--------|------|------|
| title | string | 是 | 部件名称 |

### 示例

```json
{"type":"PART","id":"partId","ticket":1}||{"title":"part.1"}
```

### GROUP（分组控制）

用于将多个图元归属为一组。

| 键名 | 值类型 | 必需 | 描述 |
|------|--------|------|------|
| parentId | string | 否 | 父级分组编号，为空则表示无父级 |
| title | string | 是 | 分组名称，无名称为空字符串 "" |

### LINE（线段）

| 键名 | 值类型 | 必需 | 描述 |
|------|--------|------|------|
| lineGroup | string | 是 | 所属的导线或总线组 id |
| startX | number | 是 | 起点坐标 X |
| startY | number | 是 | 起点坐标 Y |
| endX | number | 是 | 结束坐标 X |
| endY | number | 是 | 结束坐标 Y |
| strokeColor | string\|null | 是 | 颜色，null 为默认 |
| strokeStyle | EStrokeStyle\|null | 是 | 样式，null 为默认 |
| fillColor | string\|null | 是 | 填充颜色，"" 不填充，null 为默认 |
| strokeWidth | number\|null | 是 | 宽度，null 为默认 |
| fillStyle | ESchFillStyle\|null | 是 | 填充样式，null 为默认 |

### WIRE（导线）

原理图页和仿真页才有该图元。导线由线段组成，线段上记录导线编号。导线必须带上 NET 属性标识网络名称。

| 键名 | 值类型 | 必需 | 描述 |
|------|--------|------|------|
| groupId | string | 是 | 分组控制的编号，没有默认为空 |
| locked | boolean | 是 | 是否锁定 |
| zIndex | number | 是 | Z 轴高度，用于层级显示 |


### BUS（总线）

原理图页和仿真页才有该图元。线段上记录总线编号。总线必须带上 NET 属性标识网络名称。

| 键名 | 值类型 | 必需 | 描述 |

| zIndex | number | 是 | Z 轴高度 |
| busEntry | { [id: string]: TSchBusEntry } | 是 | 总线接入标识字典 |

### ATTR（属性）

ATTR 是一个较为通用的图元，其含义为：
1. 表达一个由键(KEY)——值(VALUE)组成的多个属性中的一个
2. 可以在画布上显示，并控制显示哪些内容，以及样式位置等

当隶属编号没有指定时，则默认隶属于当前块级图元上。

| 键名 | 值类型 | 必需 | 描述 |
|------|--------|------|------|
| partId | string | 否 | 部件编号（符号页专属） |
| groupId | string | 是 | 分组控制的编号 |
| locked | boolean | 是 | 是否锁定 |
| zIndex | number | 是 | Z 轴高度 |
| parentId | string | 是 | 隶属编号，"" 表示属于当前块 |
| key | string | 是 | 属性 Key |
| value | string | 是 | 属性 Value |
| keyVisible | boolean\|null | 是 | 是否显示 Key 值 |
| valueVisible | boolean\|null | 是 | 是否显示 Value 值 |
| positionX | number\|null | 是 | 位置 X 坐标 |
| positionY | number\|null | 是 | 位置 Y 坐标 |
| rotation | number | 是 | 旋转角度 |
| color | string\|null | 是 | 颜色 |
| fillColor | string\|null | 是 | 背景色 |
| fontFamily | string\|null | 是 | 字体名称 |
| fontSize | number\|null | 是 | 字体大小 |
| strikeout | boolean\|null | 是 | 是否加删除线 |
| underline | boolean\|null | 是 | 是否加下划线 |
| italic | boolean\|null | 是 | 是否斜体 |
| fontWeight | boolean\|null | 是 | 是否加粗 |
| align | EAlign | 是 | 对齐模式 |
| version | 2.0 | 否 | 值为 2.0 表示从 2.2 版本转换过来的数据 |

### COMPONENT（元件）

| 键名 | 值类型 | 必需 | 描述 |
|------|--------|------|------|
| groupId | string | 是 | 分组编号 |
| locked | boolean | 是 | 是否锁定 |
| zIndex | number\|null | 是 | Z 轴高度 |
| partId | string | 是 | 子库编号 |
| x | number | 是 | 位置 X |
| y | number | 是 | 位置 Y |
| rotation | number | 是 | 旋转角度（角度制） |
| isMirror | boolean | 是 | 是否镜像 |
| attrs | object | 是 | 自定义属性 |

COMPONENT 引用了 Symbol，Symbol 支持多 PART，所以带了部件编号属性指示具体哪一个。

变换顺序：
1. 按照旋转角度绕原点（0,0）逆时针旋转
2. 如果是否镜像为 1，则绕原点（0,0）所在的 Y 轴进行水平镜像
3. 根据位置进行平移
