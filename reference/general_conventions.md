# 文档约定

本章介绍嘉立创EDA专业版V2文件格式中的通用约定。

## 图元结构数组

- 文件以行为单位，每一行都是一个合法的 JSON 数组，这个数组称为 **图元结构数组**。
- 如格式无特殊说明，图元结构数组中，每一个元素的位置都是固定的，同一个元素不会出现按情况划分到不同位置的场景（除跨版本兼容外）。

## 方向与单位

- 旋转角度以逆时针方向为正，统一使用角度制。
- 若无特殊说明，所有坐标、长度、大小统一使用 **0.01 inch** 为单位。

## 唯一编号

- 几乎所有图元都要带上文件内的唯一编号。
- 几乎所有图元都带有锁定参数。对于已经锁定的图元，编辑器应表现出如下行为：
  1. 不能拖拽
  2. 不能删除
  3. 不能通过鼠标键盘调整大小
  4. 不能通过鼠标键盘调整形状

## 颜色

- 所有颜色都使用 `"#RRGGBB"` 的方式表达；如果需要表示无颜色（完全透明），则用 `""`。

## 块级图元

- 所有具有范围特性的图元，比如 `PART` 等，以及文件本身，都称作 **块级图元**。

## 布尔编码

- 所有使用“是否XXXX”描述的属性，都使用 `1` 表示是、`0` 表示否的编码方式。

## 序列与键值对

- `[xxx, xxx, xxx, xxx]` 表示一个序列。
- `{"KEY": "VALUE", "_kEy": "@vAlUe"}` 表示键值对。除格式明确指明预留的键值对，其余可自由设定，留给工具一些特殊场景自由发挥的空间。

## JSON 标准

- 本约定中未明确描述的部分（如转义等），全部依据 RFC 7195《The JavaScript Object Notation (JSON) Data Interchange Format》。
