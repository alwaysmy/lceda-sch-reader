# 工程设置与原理图

> 版本说明：基于 EasyEDA Pro V3 格式规范 §8-9

## 工程文件结构 (Project)

### 基本字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `head` | Object | 文件头信息 |
| `title` | String | 工程名称 |
| `description` | String | 工程描述 |
| `version` | String | 版本号 |
| `documents` | Array | 文档列表 |
| `settings` | Object | 工程设置 |

### documents 结构

| 字段 | 类型 | 说明 |
|------|------|------|
| `uuid` | String | 文档 UUID |
| `docType` | String | 文档类型 |
| `title` | String | 文档标题 |
| `path` | String | 文件路径 |

### docType 类型

| 值 | 说明 |
|---|------|
| `1` | 原理图 |
| `2` | 原理图库 |
| `3` | PCB |
| `4` | PCB 封装库 |
| `5` | 面板 |
| `6` | 子原理图 |

## 工程设置

### 基本设置

| 字段 | 类型 | 说明 |
|------|------|------|
| `units` | String | 单位系统 (mm/mil) |
| `precision` | Number | 精度 (小数位数) |
| `gridSize` | Number | 网格大小 |
| `snapToGrid` | Boolean | 是否吸附网格 |

### 原理图设置

| 字段 | 类型 | 说明 |
|------|------|------|
| `sheetSize` | String | 图纸尺寸 (A4/A3/A2/A1/A0) |
| `orientation` | String | 方向 (portrait/landscape) |
| `showGrid` | Boolean | 显示网格 |
| `showBorder` | Boolean | 显示边框 |


## 原理图 (Schematic)

### 文件结构

| 字段 | 类型 | 说明 |
|------|------|------|
| `head` | Object | 文件头信息 |
| `canvas` | Object | 画布设置 |
| `shape` | Array | 图形对象数组 |
| `dataStr` | Object | 原理图数据 |

### 画布设置

| 字段 | 类型 | 说明 |
|------|------|------|
| `width` | Number | 宽度 (mm) |
| `height` | Number | 高度 (mm) |
| `backgroundColor` | String | 背景色 |
| `gridColor` | String | 网格颜色 |
| `gridSize` | Number | 网格大小 |

## 原理图对象类型

### 导线 (WIRE)

| 字段 | 类型 | 说明 |
|------|------|------|
| `gId` | String | 图形 ID |
| `pointArr` | Array | 顶点数组 |
| `strokeWidth` | Number | 线宽 (mm) |
| `strokeColor` | String | 颜色 |

### 总线 (BUS)

| 字段 | 类型 | 说明 |
|------|------|------|
| `gId` | String | 图形 ID |
| `pointArr` | Array | 顶点数组 |
| `strokeWidth` | Number | 线宽 (mm) |
| `busType` | String | 总线类型 |

### 网络标签 (NETLABEL)

| 字段 | 类型 | 说明 |
|------|------|------|
| `gId` | String | 图形 ID |
| `x` | Number | X 坐标 (mm) |
| `y` | Number | Y 坐标 (mm) |
| `text` | String | 标签文本 |
| `rotation` | Number | 旋转角度 (度) |
| `netType` | String | 网络类型 |

### netType 类型

| 值 | 说明 |
|---|------|-----------|
| `input` | 输入 |
| `output` | 输出 |
| `bidirectional` | 双向 |
| `passive` | 被动 |


## 电源符号 (POWER)

| 字段 | 类型 | 说明 |
|------|------|------|
| `gId` | String | 图形 ID |
| `x` | Number | X 坐标 (mm) |
| `y` | Number | Y 坐标 (mm) |
| `net` | String | 网络名称 |
| `symbolType` | String | 符号类型 |

### symbolType 类型

| 值 | 说明 |
|---|------|
| `VCC` | 正电源 |
| `GND` | 地 |
| `VDD` | 数字电源 |
| `VSS` | 数字地 |

## 示例：原理图文件

```json
{
  "head": {
    "docType": "1",
    "editorVersion": "3.0",
    "title": "Main Schematic"
  },
  "canvas": {
    "width": 297,
    "height": 210,
    "gridSize": 2.54
  },
  "shape": [
    {
      "gId": "wire_001",
      "pointArr": [[10, 20], [30, 20]],
      "strokeWidth": 0.15
    },
    {
      "gId": "label_001",
      "x": 30,
      "y": 20,
      "text": "VCC",
      "netType": "input"
    }
  ]
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `gId` | String | 图形 ID |
| `x` | Number | X 坐标 (mm) |
| `y` | Number | Y 坐标 (mm) |

| `height` | Number | 高度 (mm) |
| `sheetUuid` | String | 子图 UUID |
| `sheetName` | String | 子图名称 |
| `fileName` | String | 文件名 |

### 子图端口 (SHEETPIN)

| 字段 | 类型 | 说明 |
|------|------|------|
| `gId` | String | 图形 ID |
| `parentId` | String | 父子图 ID |
| `x` | Number | X 坐标 (mm) |
| `y` | Number | Y 坐标 (mm) |
| `text` | String | 端口名称 |
| `pinType` | String | 端口类型 |
